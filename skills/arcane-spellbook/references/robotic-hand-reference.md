# 机械手参考：供拟人化法师之手进阶版使用

本参考只服务于未来的“多关节法师之手”，不要求基础抓握型法师之手读取或实现全部内容。它提炼公开产品资料中的工程概念；厂商参数是产品声明，不等同于独立实验室的横向评测。

## 可迁移的工程概念

### 1. 自由度与执行器不是一回事

自由度（DOF）描述可独立改变的运动变量；执行器描述提供动力的部件。一个关节可以被单独驱动，也可以通过欠驱动、联动或肌腱共享一个执行器。未来术式应分别记录：关节状态、控制通道、耦合关系和可用力矩。

### 2. 肌腱驱动与远置驱动

机械手常把电机放在掌部或前臂，通过肌腱/绳索传递拉力。这样可减小末端惯量，并允许一个驱动通道产生多个关节的协同运动；代价是存在摩擦、回差、张力分配和断腱故障。法师模型可将它转译为“施力节点在腕后，约束丝传力到指端”，而不是凭空让每个关节拥有独立动力。

### 3. 欠驱动与顺应性

欠驱动机构的输入少于关节自由度，手指会在接触物体后被动适形。它适合“先闭合、再贴合”的鲁棒抓握，但不能随意指定每个关节姿态。法术中可以把它建模为：施法者只控制闭合方向和总张力，接触几何决定各节点的最终位置。

### 4. 触觉不是单一压力读数

有用的接触反馈至少包括：接触位置、法向力、切向力、压力分布、表面几何、滑移趋势和温度。高分辨率触觉传感器还可从接触图像估计物体姿态。法术模型应区分“已经碰到”“压得多大”“正在滑”和“物体是什么形状”。

### 5. 力控制与位置控制要分开

位置控制回答“末端到哪里”；力控制回答“接触时施加多大力”。精密抓握常在自由空间使用位置控制，接触后切换到力、阻抗或导纳控制。拟人化术式可以用“自由段 - 接触段 - 操作段”三态控制器表达这一切换。

### 6. 闭环频率与延迟

机械手不是施加一次命令后等待结果，而是反复读取传感器、比较目标和实际状态、再更新控制量。控制频率、感知延迟和执行延迟决定可修正的扰动速度。法术中应给出更新周期或至少给出“感知太慢时必须降速”的边界。

### 7. 姿态规划与逆运动学

当目标是拟人手势时，施术者不能直接从“手尖去这里”得到每个关节的角度。需要先定义末端位姿，再求一组满足关节限位、碰撞约束和连续性的关节解。可学习：坐标变换、雅可比矩阵、逆运动学、奇异位形、轨迹插值和约束优化。

### 8. Teleoperation 与示教

真实机械手常通过数据手套、主从设备或示教轨迹获得人类动作，再由控制器完成尺度转换和约束。对应到法术，可以把施法者的手部动作视为高层意图输入，而不是逐关节实时操纵；这能解释“手势简单但代理手动作复杂”。

## 未来进阶术式的建议状态表

| 类别 | 变量示例 |
|---|---|
| 关节状态 | $\boldsymbol{q}$、$\dot{\boldsymbol{q}}$、关节限位 |
| 末端状态 | 位置 $\boldsymbol{x}$、姿态 $\boldsymbol{R}$、速度 |
| 驱动状态 | 肌腱张力、执行器余量、回差 |
| 接触状态 | 接触点、法向力、切向力、滑移速度 |
| 目标状态 | 物体姿态、质量估计、抓握任务 |
| 控制输入 | 目标位姿、闭合力、阻抗参数、释放条件 |
| 约束 | 自碰撞、物体破坏阈值、稳定性、法力消耗和延迟 |

## 适合转译的控制模型

- **抓握稳定性：** 摩擦锥、力闭合、扭矩平衡和重心投影。
- **柔顺接触：** 弹簧-阻尼近似、阻抗控制、接触状态机。
- **轨迹跟踪：** 位置误差反馈、速度前馈、有限增益和抗饱和。
- **滑移检测：** 触觉变化率、切向振动和压力中心移动。
- **多指协调：** 任务空间/关节空间分离、抓握力与操作力分解。
- **安全退让：** 力或速度超过阈值时降增益、松弛肌腱、撤回末端。
