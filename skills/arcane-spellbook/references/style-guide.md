# 法术书行文与排版规范

将法术书写成学院教材，不写成设定百科、角色独白或说明书翻译腔。读者应感到一位熟悉训练现场、知道学生会在哪一步误判的教员正在讲授一项可练成的技术。

## 基调

- 保持冷静、具体、克制。用“本术”“施法者”“学生”“教员”和“训练场”建立教学关系。
- 将法力写作一切术式唯一的能量来源。热、冲量、约束、运动、共鸣等只能作为法力的转化通道、术式状态或消耗项目；正文不得另立“弧能”“元素能”等并列能量。
- 术式正文使用“法力输入”“法力预算”“释放法力”“持续功率”“安全法力余量”等词；“能量”只用于解释守恒思想或引用外部学科，不作为第二种可计量资源。
- 先给出可观察的事实，再给出原因，最后给出动作或判断。不要只下结论。
- 在定义段使用正向陈述：说明术式构造什么、作用于什么、如何完成任务及其适用范围。不要以“它不是……”或对现实对象的否定作为定义主干。
- 允许简短的人话式提醒，例如“不要急着增加法力输入”或“这里最容易看错的不是距离，而是延迟”。提醒后必须接着解释相关变量、征兆或后果。
- 把失败当作可诊断的学习材料，不把学生写成愚蠢，也不把熟练写成神秘天赋。
- 让专业性来自清晰的因果链、单位、限制和检验，而不是堆砌术语。

## 段落节奏

大多数技术段落按以下顺序组织：

1. 说明本节解决的实际问题。
2. 引入少量新量，并用一句话说明其可测量或可控制的含义。
3. 给出公式、规则或算法。
4. 翻译成施法者在场上要看见什么、计算什么、做什么。
5. 给出一个常见误判、失效边界或安全判断。

不要让公式孤立出现。公式前说明它回答什么问题，公式后说明它改变哪一个决定。

## 推荐句式

使用主动、可执行的表达：

- “先确认 $M\ge1.25$，再允许火球离手。”
- “这个式子不用于临场求解；它用于制作构型卡。”
- “半径加倍时，核心成本约增至八倍，因此先问范围是否真的需要扩大。”
- “若两次修正后边界仍在拉长，停止补壳并转入消散。”

在解释概念时，可以使用正向的任务对照句：

- “本术以受约束的热核提供高温，并由壳层维持边界。”
- “这里求的是满足误差上限的可用发射解。”
- “防护以可读入的阈值三元组进入模型。”

## 避免的写法

- 不写空泛判断：如“注入大量法力”“精确控制”“注意安全”。改为写明输入、上限、征兆和动作。
- 不以否定句替代术式定义。若必须澄清误解，把区分放在定义之后，并写清实际机制。
- 不用玄奥名词掩盖未定义的机制：如“调整元素共鸣”或“提高法力频率”。除非它是可测变量且有定义。
- 不让教员以全知口吻保证结果。使用“在此近似下”“只在以下条件成立时”“若观测不足则中止”。
- 不把现有物理定律直接套入术式。明确哪些关系来自学院定律，哪些关系只用于类比、维度检查或建模起点。
- 不连续堆叠超过三个未解释的术语、变量或修饰语。
- 不使用夸张的威胁、史诗化宣言或小说化的感官描写替代技术说明。

## 数学排版

- 行内符号使用 `$...$`：$E_r$、$\eta_h$、$M\ge1.25$。
- 独立方程使用 `$$...$$`。多行推导用 `\begin{aligned}...\end{aligned}`。
- 下标、希腊字母、分式与根式必须采用 LaTeX：$E_{r,\mathrm{plan}}$、$\Delta y$、$\frac{d}{v_0}$、$\sqrt{x}$。
- 普通物理量采用 SI 单位：$0.20\,\mathrm{m}$、$0.05\,\mathrm{s}$、$293\,\mathrm{K}$。法力统一以学院单位 $\mathrm{ae}$ 计，例如 $60\,\mathrm{ae}$。
- 避免用反引号包住变量或单位。反引号只用于文件名、命令和非数学代码。
- 不使用 Unicode 上下标、角标或裸希腊字母代替 LaTeX；例如写 `$T_a$`、`$\Delta y$`、`$\mu$`，不要写 `Tₐ`、`Δy` 或 `μ` 作为公式。

## 章节层次

- 开头用一小段明确本术构造什么、作用于什么、解决什么问题和适用范围。不要用宏大世界观开场。
- 理论部分从直觉模型走向公式；不要先抛完整方程再补定义。
- 实操部分采用短编号步骤，并在关键步骤说明身体动作的技术功能。
- 用表格呈现“征兆 - 诊断 - 修正 - 中止界限”与“变量 - 含义 - 获取方式”。表格服务于检索，不取代解释。
- 习题按“计算、模型选择、误差诊断、实操判断”混排。答案除给结果外，说明决定该结果的模型条件。

## 收尾检查

- 每一节是否能回答学生自然会问的“为什么”和“接下来怎么做”？
- 是否至少有一处用训练中的常见误判来解释模型边界？
- 读者能否区分课后推导、构型卡、临场心算和紧急中止？
- 删除术语后，剩下的因果关系是否仍清楚？若不清楚，先补过程，不要加新名词。
- 正文是否像学院教材中的直接授课，而不是作者向现代读者解释设定？
- 术式的每一笔法力是否都能追溯到构造、维持、运动、释放、损耗或安全中止？
